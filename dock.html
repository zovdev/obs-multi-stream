Расширенные: свой Google-клиент (не обязательно)
Как создать свой клиент (один раз, ~5 минут)
  1. console.cloud.google.com → создать проект
  2. APIs & Services → Library → включить YouTube Data API v3
  3. APIs & Services → OAuth consent screen → External, добавить свой аккаунт в Test users
  4. Credentials → Create Credentials → OAuth client ID
  5. Тип: Desktop application ← обязательно!
  6. Скопировать Client ID и Client Secret сюда
